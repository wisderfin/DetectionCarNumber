# DetectionCarNumber

## О проекте

Данный проект был написан с целью изучения библиотеки `PyTorch` и знакомства с `ML`.

## Подготовка данных

*[Датасет](https://www.kaggle.com/datasets/evgrafovmaxim/nomeroff-russian-license-plates) для тренировки.*

Загрузите датасет(удобным для вас способом) и поместите все исходники в директорию `src`, так что бы у вас получилась следующая структура.
```text

DetectionCarNumber
└──src
  ├──train
  │  ├──img
  │  └──ann
  ├──test
  │  ├──img
  │  └──ann
  └──val
     ├──img
     └──ann
```

Для загрузки датасета был написан класс `ValidationDataset` унаследованый от базового класса `torch.utils.data.Dataset`. В нём была реализована логика подгрузки изображений специально под специфику загруженого датасета. Так же были переопределены методы `__len__` для выдачи размера загруженного датасета и `__getitem__` для получения данных по индексу в уже преобразованном для модели формате.

## Модель

В качестве архитектуры модели была выбрана `CRNN`.

> `CRNN` - архитектура объеденяющая в себе CNN(сверточные слои) и `RNN`(рекурентные слои). `CNN` используется для нахождения пространственых признаков(в нашем случаи, закономерностей в изображениях), в `RNN` для нахождения и распознования последовательностей(символов номерного знака)

В модели было реализвано 6 слоёв:
- `CNN`
	- `Conv2D` - разделяет изображение на сегменты и ищет ключевые признаки.
	- `ReLU` - функция активации(ускореяет обучение и добавляет нелинейности в алгоритм)
	- `MaxPool2D` - разделяет сегменты полученые из `Conv2D` еще на несколько сегментов и оставляет из них только самые характерные(уменьшает длительность обучения и учит модель больше обобщать)
	- `Conv2D` - снова ищем принаки
	- `ReLU` - снова добавляем нелинейности
	- `MaxPool2D` - снова обобщаем
- `RNN`
	- `LSTM` - решает какую информацию нужно запомнить или забыть
- `FC`
	- Linear - базовый слой для построения выходных нейронов (он решает что в коннечном итоге будет результатом, основываясь на результате преведущего слоя)

Был написан метод `forward`, который прогоняет входные данные(image, label) через выше описаные слои и выдаёт результат

## Обучение

Написана функция `train_epoch` выполняющая одну эпоху тренировки. На каждом шаге происходит обработка изображения, вычисление предсказания модели, вычисление потери и обновление параметров модели.

При запуске файла` train.py`:
- Загружается датасет (через `ValidationDataset`)
- Подготавливаются батчи. Подготовка происходит через функцию `collate_fn`, выполняющий 2 действия:
	- Паддинг меток до одинаковой длинны(`pad_sequence`)
	- Стекирование изображений в тензор(`torch.stack`)
- Применение модели (`CRNN`) к данным
- Вычисление потерь
- Повторение тренировки EPOCH  раз (EPOCH переменая, хранимая в `utils.py`)
- Сохранение модели в формате `.pth`
